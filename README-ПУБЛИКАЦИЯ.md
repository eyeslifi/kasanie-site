# Касание — пакет для размещения

## Содержимое
- `index.html` — главная страница сайта.
- `assets/` — изображения, вынесенные из HTML без изменения их содержимого.
- `ASSET-MANIFEST.json` — контрольные суммы и размеры файлов изображений.

## Размещение на GitHub Pages
1. Создайте публичный репозиторий GitHub, например `kasanie-site`.
2. Загрузите в корень репозитория `index.html`, папку `assets` и этот файл.
3. В репозитории откройте `Settings` → `Pages`.
4. В источнике публикации выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем сохраните.
5. Дождитесь завершения публикации. Адрес будет вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/kasanie-site/`.

## Перед публикацией
- Репозиторий должен быть публичным для бесплатного размещения на GitHub Pages. Это делает исходные файлы доступными другим людям.
- Не переименовывайте и не перемещайте `assets`, если не обновляете пути в `index.html`.
- После публикации проверьте сайт на компьютере и телефоне: навигацию по секциям, тест, итоговый экран, сохранение карточки результата, раскрытие прайса и ссылки Telegram.
- Внешние шрифты загружаются с Google Fonts, поэтому для их отображения требуется подключение к интернету; при недоступности сервиса страница использует резервные системные шрифты.
- Пакет не содержит серверной части или базы данных: результаты теста работают в браузере и не отправляются на сервер сайтом.


После публикации при необходимости добавьте в `<head>` канонический адрес нового размещения и укажите его в структурированных сведениях (`url`). До выбора постоянного адреса оба поля не указывают на прежний сайт, чтобы не вводить поисковые системы в заблуждение.
